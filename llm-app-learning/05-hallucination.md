# 05 · 幻觉及其成因（Hallucination）

> 幻觉是 LLM **一本正经地生成看似合理、实则错误或无依据**的内容——它不是偶发 bug，而是"按概率续写"这一本质的**固有副产品**；理解成因才能理性治理。重要度 ⭐⭐⭐。

## 🎯 一句话核心

模型优化的目标是"**像不像**"（下一个 Token 的概率），而不是"**对不对**"（事实真值）——所以当它"不知道"时，也会用最流畅、最自信的措辞**编一个看起来对的答案**。幻觉不能根除，只能靠工程手段**压低**。

## 📖 核心原理

**幻觉的根源，就是 [01-llm-overview](01-llm-overview.md) 讲的那个本质：LLM 是"预测下一个 Token 的概率续写器"。** 它训练时的唯一目标是让生成的文本**在统计上最像**训练语料里会出现的文字，而**没有任何一个环节在校验"这句话是不是真的"**。当上文是"《XXX》这本书的作者是"，模型会填一个"最像作者名的 Token 序列"——哪怕这本书根本不存在。**流畅 ≠ 正确**：幻觉之所以危险，正是因为它和真话用的是同一套"高概率、高自信"的生成机制，从措辞上分辨不出来。

**为什么它倾向"自信地编"而不是"承认不知道"？** 几个叠加原因：

1. **训练里几乎没有"我不知道"的信号。** 预训练语料是人写的成品文本，极少出现"这个我不清楚"这种句子；SFT/对齐阶段又主要奖励"给出有用回答"。于是模型学到的隐含策略是**永远给答案、给得越顺越好**，而不是校准自己的不确定性。
2. **知识以"模糊的参数"形式存储，边界不清。** 模型没有一张可查的知识表，知识被压缩、分散在千亿参数里。常见事实存得"清晰"，长尾/冷门事实存得"模糊"——但模型**分不清自己哪块记得牢、哪块在瞎猜**，于是对模糊记忆也照样自信输出。
3. **对齐带来的"取悦倾向"（sycophancy）也助长幻觉。** RLHF 让模型倾向于顺着用户、给肯定回答；当用户的问题预设了一个错误前提（"请介绍一下 X 定理"，而 X 定理并不存在），模型更可能**顺着编**而不是反驳。
4. **采样的随机性**（详见 [04-sampling-decoding](04-sampling-decoding.md)）让它在概率分布里"抽"到偏离事实的 Token，temperature 越高越容易发散。

> 一句话：幻觉 = 「优化目标错位（像 vs 对）」+「无不确定性信号」+「知识边界模糊」+「取悦倾向」+「采样随机」的合力。它和模型的"聪明"同源——**同一个概率续写能力，既写出正确答案，也编出假答案**。

## 🔧 关键方法 / 流程 / 架构

**先分清两类幻觉（治理手段不同，这是关键区分）：**

| 类型 | 定义 | 典型场景 | 主要治理 |
|---|---|---|---|
| **事实性幻觉**（Factual）| 输出**与真实世界矛盾**（假事实、假引用、假 API、假数字）| 无外部依据的开放问答 | RAG 补事实、工具核查 |
| **忠实性幻觉**（Faithfulness）| 输出**与给定上下文/材料矛盾或超出材料** | **RAG / 摘要 / 抽取** | 约束"仅依据材料"、引用溯源、评估 |

> 在 RAG 场景里，**忠实性幻觉才是主战场**：材料明明给对了，模型却"脑补"出材料里没有的内容，或篡改材料里的数字——这是 RAG 评估里 `Faithfulness` 指标专门盯的问题（详见 [26-llm-evaluation](26-llm-evaluation.md)）。

**治理手段是"分层压低"，从依据、生成、兜底三层入手：**

```
                     幻觉治理分层（从"给依据"到"兜底")
┌───────────────────────────────────────────────────────────┐
│  ① 提供事实依据（最有效，治本）                             │
│     └─ RAG：把真实资料检索出来喂进上下文 → 让模型"抄"而非"编" │
│        工具调用：查数据库/算数/取实时数据（精确计算交给工具）  │
├───────────────────────────────────────────────────────────┤
│  ② 约束生成（降低编造概率）                                 │
│     ├─ 降 temperature → 少发散、多取高概率 Token             │
│     ├─ Prompt 约束："仅依据以下材料回答""材料没有就说没有"    │
│     ├─ 要求引用溯源：每个结论标出处 → 可核查、也抑制乱编      │
│     └─ 结构化输出：限定 JSON/枚举/字段 → 缩小"自由发挥"空间   │
├───────────────────────────────────────────────────────────┤
│  ③ 事后校验兜底（承认压不到 0，加一道关）                   │
│     ├─ LLM-as-judge / 事实核查：让另一模型或规则查一致性     │
│     ├─ 引用回链校验：结论能不能在原文里对上                  │
│     └─ 高风险场景人工确认（医疗/法律/金融/对外承诺）         │
└───────────────────────────────────────────────────────────┘
   效果排序：给对依据(①) ≫ 约束生成(②) ＞ 事后兜底(③)
```

**为什么 RAG 是最有效的一层？** 因为它直接改变了模型的"续写素材"：与其让模型从模糊参数里"回忆"，不如把权威资料放进上下文，让它变成**基于材料的阅读理解**（模型很擅长这个）。这也是 [14-rag-overview](14-rag-overview.md) 存在的核心动机之一。但要注意——**RAG 只是把幻觉压低，不是消除**：检索错了、检索到了但模型没用上、或材料本身有错，照样会幻觉（见下方易错点）。

## 🔑 要点速记

- 幻觉 = **看似合理、实则错误/无依据**的生成（假事实、假引用、假 API、假数字）。
- 根因是本质：LLM 优化"**像不像**"（概率续写）而非"**对不对**"（事实）——和它的智能**同源**。
- 助推因素：训练**无"我不知道"信号**、倾向自信作答；知识以**模糊参数**存储、边界不清；对齐带来**取悦倾向**；采样随机。
- 两类：**事实性幻觉**（与世界矛盾）vs **忠实性幻觉**（与给定上下文矛盾，RAG 场景关键）。
- 治理分层：**① RAG/工具给依据（最有效）→ ② 降温/溯源/"仅依据材料"/结构化约束 → ③ 评估校验 + 人工兜底**。
- 效果排序：**给对依据 ≫ 约束生成 ＞ 事后兜底**；能治本别只治标。
- ⚠️ **不能根除，只能压低**——它是概率生成的固有属性，连 RAG 也会因检索错/没用上而幻觉。

## ❓ 高频面试 / 理解题

**Q：大模型为什么会产生幻觉？**
A：因为它本质是"预测下一个 Token 的概率续写器"，训练目标是让文本**统计上最像**真实语料，而**全程没有校验"这句话是不是真的"**。当它对某事实记得模糊或根本不知道时，仍会用最流畅、最高概率的措辞"编"一个看起来对的答案。再叠加三点：训练里几乎没有"我不知道"的样本（倾向自信作答）、知识以模糊参数存储导致它分不清自己哪里在瞎猜、以及对齐带来的取悦倾向。所以幻觉和模型的"聪明"是**同一个能力的一体两面**。

**Q：事实性幻觉和忠实性幻觉有什么区别？为什么 RAG 里要特别关注后者？**
A：事实性幻觉是输出与**真实世界**矛盾（如编造一个不存在的定理）；忠实性幻觉是输出与**给定的上下文材料**矛盾或超出材料（材料没说，它却脑补）。RAG 里材料通常是对的，风险恰恰是模型**不忠实于材料**——篡改数字、添加材料里没有的结论。这正是 RAG 评估里 `Faithfulness` 指标要量化的东西（[26-llm-evaluation](26-llm-evaluation.md)）。

**Q：有了 RAG 是不是就没有幻觉了？**
A：不是。RAG 是**最有效**的手段但不能消除幻觉，原因有三：①检索错了（召回到不相关或错误的材料，模型照着错答）；②检索对了但模型**没用上或用错**了材料（忠实性幻觉）；③材料本身就有错。所以 RAG 之上还要叠加"仅依据材料回答"的约束、引用溯源、以及评估/人工兜底。幻觉是概率生成的固有属性，工程上只能**分层压低**，不能归零。

## ⚠️ 易错点 / 实践建议

- ⚠️ **别把幻觉当"可修复的 bug"**——它是"预测下一个 Token"这一本质的**固有属性**，任何单一手段都只能压低概率，不能保证为 0；系统设计要按"它一定会偶尔编"来做兜底。
- ⚠️ **流畅 ≠ 正确，越自信越危险**——幻觉和真话共用同一套高置信生成机制，肉眼/语气分辨不出来；高风险结论必须能**回链到出处**核查，而不是信它的口气。
- ⚠️ **RAG 也会幻觉**：检索错、检索到没用上、材料本身错，都会导致忠实性幻觉。上了 RAG 别以为万事大吉，要配 `Faithfulness` 评估定位是"检索问题"还是"生成问题"（[19-rag-evaluation](19-rag-evaluation.md)）。
- ✅ **优先治本再治标**：能加事实依据（RAG/工具）就别只靠调 Prompt 和降温；效果排序是**给对依据 ≫ 约束生成 ＞ 事后兜底**。
- ✅ **显式给"不知道"的出口**：Prompt 里明确"材料中没有就回答'不知道/资料未提及'，不要猜测"，能显著减少硬编——因为模型默认策略是"永远给答案"。
- ✅ **加分认知**：能说清"幻觉与模型智能同源于'预测下一个 Token'"，并据此把 RAG/溯源/评估/护栏串成一条**分层压低不确定性**的主线，比只会背"幻觉的几种类型"更显理解本质。
