# 大模型应用核心原理系统学习 · 统一规范（所有 sub-agent 必须遵守）

> 本文件是本子库唯一风格标准。任何 agent 生成内容前先读本文件。
> 定位：**框架无关的原理系统学习**——讲透 RAG / Agent / Embedding / 评估 / 安全等**概念、原理、方法与架构**，不绑定具体框架、不堆 API。

## 一、与姊妹内容的分工（重要，别越界）

| 内容 | 定位 | 形态 |
|---|---|---|
| `../spring-ai-learning` 等 | **框架怎么写代码**（Spring AI / LangChain4j / Alibaba） | 可运行 Maven 模块 |
| **本库 `llm-app-learning`** | **原理是什么、方法怎么设计**（框架无关） | 一个知识点一篇原理长文 + 架构图 |
| `../../interview/05-ai` | **面试怎么速答** | 短问快答速记卡 |

原则：本库讲 **how/why 与方法论**（RAG 为什么这么设计、Agent 编排怎么选、评估怎么做），涉及具体落地代码时**一句话链接到框架库**（如 `Spring AI 实现见 ../spring-ai-learning/11-rag-etl`），不复制框架代码；涉及面试速答时链接 `../../interview/05-ai`。

```markdown

（方法论、步骤、设计权衡；**复杂机制配 Mermaid 或 ASCII 架构/流程图**。可用框架无关的伪代码或极简示例说明，但不堆某框架 API。）
```

> 深度要求：**讲原理和方法论**（RAG 每步为什么、检索为什么要 rerank、Agent 为什么不稳、评估怎么量化、微调 vs RAG 怎么选），不是概念名词堆砌，也不是框架 API 教程。

## 四、内容语言与质量底线

- 讲解一律**中文**；术语/模型/方法名用英文（如 `RAG`、`Rerank`、`ReAct`、`HNSW`、`Faithfulness`、`LoRA`）。
- **框架无关**：讲通用原理与方法；需要具体代码时链接对应框架库，不在此展开。
- 复杂主题**必配图**（RAG 全流程、Agent 编排、检索两阶段、评估管道、注意力概念图等）。
- 每篇聚焦一个知识点，篇幅充实但不灌水；突出"原理 + 方法 + 权衡 + 踩坑"。
- 相关知识点用相对链接互引（如 `详见 [14-rag-overview](14-rag-overview.md)`）；面试速答链 `../../interview/05-ai`，框架实现链 `../spring-ai-learning`。
- 基线：以 2024–2026 的主流实践为准（GPT-4/Claude/开源模型通用），点明概念而非绑定某模型版本。

## 五、覆盖主线（六阶段）

1. **大模型基础原理**：LLM 是什么 → Transformer/注意力（概念级）→ Token/分词 → 采样解码 → 幻觉 → 上下文工程。
2. **Prompt 工程**：基础 → CoT/推理增强 → 结构化输出 → Prompt 安全。
3. **Embedding 与向量检索**：Embedding 原理 → 相似度/ANN → 向量数据库。
4. **RAG 检索增强（核心）**：动机 → 分块 → 检索优化 → Rerank → 高级架构 → 评估。
5. **工具调用与 Agent**：Function Calling → MCP → Agent/ReAct → 编排模式 → 多智能体 → 记忆规划。
6. **评估·安全·工程化**：评估 → 护栏安全 → 微调定制 → 推理优化 → 应用架构落地。
